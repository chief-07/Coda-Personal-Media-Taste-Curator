# Coda

Coda is a personal recommendation companion built around one intentional pick at a time.

The app is mobile-first Flutter. The recommendation intelligence is intentionally kept behind a backend boundary so the app can stay focused on taste, conversation, and polished interaction.

## Stack

- Flutter and Dart
- Riverpod for app state
- go_router for navigation
- Feature-first project structure

## Run

```sh
flutter pub get
flutter run
```

## Verify

```sh
dart analyze
flutter test
```
